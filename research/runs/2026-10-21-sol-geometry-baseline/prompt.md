# Geometry baseline evidence work package

Create reproducible, source-backed geometry evidence before any Astra optimization run.

Requirements:

- Inspect the pinned upstream CarConcept, sanitized web derivative, and integrated Estuary control with one reusable read-only geometry reporter.
- Record exact bytes, SHA-256, nodes, meshes, primitives, materials, textures, images, triangles, indexed render vertices, uploaded POSITION vertices, bounds, variants, extensions, forbidden nodes, and independent parser status.
- Render the upstream source, sanitized baseline, Estuary integration, and a readable topology detail with a fixed 600×400 browser harness.
- Pin every rendered model to the asset manifest and reject browser errors, failed requests, empty wireframe output, or changed repeated readback.
- Visually inspect every image.
- Keep all authoring, capture, metric generation, and review attributed to Sol rather than Astra.
- Do not modify or optimize model bytes in this work package.
