# Geometry toolchain preflight notes

## Result

Passed for a deterministic glTF/WebGL optimization work package. The environment is **not** capable of a Blender/bpy DCC geometry-authoring pass, and later work must not claim one.

## Pinned toolchain

- Node v26.10.0 and npm 11.19.1.
- glTF Transform CLI/core/extensions/functions 4.5.1.
- meshoptimizer 1.2.0, explicitly pinned and importable.
- official Khronos `gltf-validator` npm package 2.0.0-dev.3.10.
- Playwright 1.64.1 with Chromium 156.0.8078.4, revision 1248.
- Immutable source: `public/assets/models/product-estuary.glb`, 10,191,496 bytes, SHA-256 `bc82c38a61513010d850d329d0e1e618fc7135bad0ab0bd11e5bd83cffe4834f`.

Blender, `bpy`, and standalone `gltfpack` are unavailable. The pinned glTF Transform/meshoptimizer path can perform deterministic simplification, but this preflight does not establish Blender editability or DCC authorship.

## Reproducible capability probe

`run-preflight.mjs` clears an ignored scratch directory and records exact argv, cwd, timing, exit status, stdout, and stderr for each probe. It then runs the same conservative simplification twice from the immutable control:

`gltf-transform simplify <source> <scratch-output> --ratio 0.95 --error 0.001 --lock-border true`

Both outputs were byte-identical at 9,852,752 bytes with SHA-256 `f067a32c42f4018fb7011693207b2b97909eeb8b6d60c9b230fc904bab2cd2c5`.

The independent reporter measured:

- 202,687 triangles;
- 608,061 submitted triangle indices;
- 156,572 distinct POSITION accessor entries;
- unchanged 107 primitives, 95 meshes, 30 materials, 14 textures, and 14 embedded images;
- all four variants retained with 25 mapped primitives each;
- no forbidden nodes.

The scratch outputs live only under ignored `.cache/geometry-preflight/` and are regenerated by the preflight script. They are infrastructure evidence, not Safe WebGL or Mobile LOD candidates, have no visual acceptance, and receive no optimization credit.

## Browser and validator evidence

The pinned Chromium executable was hashed and launched successfully with WebGL2. It reported SwiftShader through ANGLE/Vulkan. These software-renderer facts support deterministic regression work only, not production-GPU performance claims.

The scratch probe produced zero validator errors, 28 warnings, 15 infos, and zero hints. All messages were in four known groups: unsupported extension, KTX2 MIME value, unused image object, and unrecognized image format. This validator build does not fully understand `KHR_texture_basisu`/`image/ktx2`; zero errors demonstrates parser acceptance under this build, not full current Khronos conformance certification.

## Security audit

The audit captured on 2026-10-21 reported zero production vulnerabilities and three high-severity development-only findings in the `@gltf-transform/cli` → `micromatch` → `braces` chain. At capture time npm proposed a major downgrade to glTF Transform 2.0.5 rather than a compatible fix. The pinned 4.5.1 toolchain is retained for this experiment, and scored transformation commands must use repository-controlled paths and arguments only.

## Readiness decision

Astra may begin one isolated Safe WebGL work package from the immutable Estuary control, using only the pinned glTF Transform/meshoptimizer path and disclosing the absence of Blender. The scored package must still produce authentic private session evidence, deterministic reproduction, semantic checks, visual evidence, browser measurements, and independent review. Mobile LOD requires a second fresh Astra session starting again from the immutable control.
